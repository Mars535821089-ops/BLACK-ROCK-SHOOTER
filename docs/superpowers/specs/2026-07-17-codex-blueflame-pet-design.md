# Codex BLACK★ROCK SHOOTER Pet 设计说明

## 目标

制作一款能够显示 Codex 任务状态的原生自定义 Pet。Pet 安装后出现在 `Settings → Pets → Custom pets`，可像内置 Pet 一样选择、唤醒，并通过 Codex 原生 `Pet size` 滑杆连续放大或缩小。第一版完成 Codex 窗口内与原生浮动 Pet；后续可复用同一角色资产开发独立 macOS 桌面悬浮版本。

## 已确认的角色设计

- 角色为七头身、正常动漫少女比例，始终从头到脚完整呈现，不做 Q 版。
- 整体形象尽量贴近用户提供的参考图，但不是直接复制其中某一张全身形象。
- 固定辨识特征：黑色高双马尾、侧刘海、冰蓝眼睛、画面右侧眼睛（角色解剖学左眼）上方蓝色火焰。
- 服装：黑色短款连帽外套、白色袖条与星形标记、黑色短裤、白色腰带、黑手套、及膝战术长靴。
- 绘制风格：平滑赛璐璐动漫风、透明背景、黑蓝冷色调。
- 性格：外冷内萌。平时冷淡克制，在等待、点击互动或任务完成时出现轻微可爱反应。
- 武器：黑色长刀，银蓝刃线。待机和等待时隐藏，只在执行、完成和失败等关键状态出现。

## 参考图的使用边界

- `IMG_2189.JPG` 与 `IMG_2188.JPG` 用于提取发型、眼睛、位于画面右侧眼睛上方（viewer-right eye，角色解剖学左眼）的蓝焰、服装语言和人物气质。
- `IMG_2190.PNG` 仅用于确认角色需要长刀武器和持刀气质。
- 三张图都不是最终角色母版。最终母版需要重新设计完整身体、统一互相冲突的细节，并为小尺寸 Pet 优化轮廓。

## 制作方法

采用“角色母版 → 状态关键帧 → 原生 spritesheet”的方式：

1. 先生成并人工检查一张完整角色母版，锁定脸、发型、服装、身体比例和武器。
2. 以母版为唯一角色参考，制作各个 Codex 状态的关键帧，避免不同动作变脸、换装或改变身体比例。
3. 将关键帧整理成 Codex Pet v2 标准动画表。
4. 生成 `pet.json`，安装到 Codex 原生自定义 Pet 目录。

不采用一次性生成整张动画表，因为人物一致性不可控；不采用二维骨骼绑定，因为制作周期更长且容易产生纸片感。

## 状态动作映射

| Codex 状态 | 动作设计 | 武器 |
| --- | --- | --- |
| `idle` | 冷脸站立，双马尾和外套轻微摆动 | 隐藏 |
| `waiting` | 抱臂等待回复，偶尔歪头眨眼 | 隐藏 |
| `running` | 拔出长刀进入战斗姿态，蓝焰增强 | 显示 |
| `running-left` | 持刀向左快速移动 | 显示 |
| `running-right` | 持刀向右快速移动 | 显示 |
| `review` | 观察蓝色悬浮代码片 | 隐藏 |
| `waving` | 挽刀花后收刀，短暂微笑 | 显示后隐藏 |
| `failed` | 长刀插地，单膝蹲下，蓝焰变弱 | 显示 |
| `jumping` | 被点击后轻跳，随后装作若无其事 | 隐藏 |

## Codex 原生资产格式

- Pet 版本：v2。
- 动画表尺寸：`1536 × 2288`。
- 网格：8 列 × 11 行。
- 单帧：`192 × 208`。
- 交付格式：透明背景 WebP。
- 配套清单：`pet.json`，包含显示名、描述、`spriteVersionNumber: 2` 和 spritesheet 文件路径。
- 保留可编辑的角色母版、状态关键帧和动画表组装源文件，便于后续修正。

## 安装与数据流

1. 构建脚本验证动画表尺寸、格式和透明通道。
2. 安装脚本在 Codex `pets` 目录中新建独立 Pet 文件夹。
3. 动画表与 `pet.json` 先写入临时目录，完整验证后再原子替换目标目录。
4. 用户在 `Settings → Pets` 点击 Refresh 后看到新 Pet，并通过 Select 启用。
5. 用户通过 Pets 设置中的原生 `Pet size` 滑杆调整外观大小；自定义 Pet 不提供第二套缩放状态。
6. Codex 根据任务状态选择对应动画行；Pet 本身不读取聊天内容，也不新增网络请求。

## 错误处理与回滚

- 资产尺寸、文件格式、透明通道或清单字段不合法时停止安装。
- 更新已有 Pet 前创建本地备份；新版本验证成功后才替换旧版本。
- Codex 未加载新 Pet 时保留产物，并提示用户在 Pets 设置中 Refresh，不修改客户端包。
- 任何失败都不得破坏现有内置 Pet 或用户已有的其他自定义 Pet。

## 验收标准

- 新 Pet 出现在 Codex 原生 Custom pets 列表并可选择。
- Codex 原生 `Pet size` 滑杆能够连续放大和缩小该 Pet，行为与内置 Pet 一致，切换任务或重启后保持所选尺寸。
- 九种原生状态均能播放正确动画，左右移动方向正确。
- 待机与等待状态没有武器；执行、完成、失败状态符合武器规则。
- 人物在全部关键帧中保持同一张脸、同一发型、同一服装和七头身比例。
- 所有帧完整显示人物身体和需要出现的整把长刀，没有被单帧边界裁切。
- 在原生滑杆的最小尺寸 80 px、默认尺寸和最大尺寸 224 px 下，脸、蓝焰、身体轮廓和状态动作仍可辨认；放大后边缘不出现额外白边，缩小后不丢失关键轮廓。
- 背景透明，无白边、脏边、闪烁或帧间位置跳变。
- Codex 正常更新不会覆盖自定义 Pet 目录中的安装结果。

## 第一版范围外

- 不修改或重新打包 Codex 客户端。
- 不增加新的 Codex 设置页面。
- 不实现联网同步、Pet 商店或多角色系统。
- 不在第一版中制作独立 macOS 桌面悬浮应用；该能力留作第二阶段。
